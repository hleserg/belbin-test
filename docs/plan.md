# План реализации

1. Извлечь текст PDF в данные; сохранить 56 утверждений, 7 заголовков, 8 описаний. Проверить ключ независимо по формулам Excel, контрольный ответ и каждое отдельное утверждение.
2. Создать чистые функции проверки баллов, расчёта, выбора крайних ролей с равенствами и валидации сохранения. Сначала тесты: недопустимая единица, дроби, неверная сумма, неполный тест, повреждённое сохранение, равные результаты.
3. Создать интерфейс с семантической разметкой, клавиатурным управлением, мобильной компоновкой, статусом сохранения и выводом результатов без изменения исходного текста.
4. Собрать dist/index.html без внешних ресурсов. Проверить синтаксис, расчёты, соответствие встроенных данных исходникам, сохранение и восстановление. Браузерная проверка возможна только при доступном штатном инструменте браузера.
5. Сохранить готовую поставку. Проверить возможности GitHub; загрузить только в подтверждённый репозиторий, настроить публикацию только при доступной операции. Отдельно сообщить ограничения публикации и проверки доступности из России.
