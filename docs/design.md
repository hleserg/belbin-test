# Веб-версия выданного теста Белбина

Назначение: комфортно пройти тест, выданный организатором волонтёрского проекта против буллинга, и подготовить результаты для обсуждения.

Источник формулировок, заголовков, инструкции и описаний: предоставленный PDF. Ключ PDF совпадает со всеми 56 ссылками Excel. Расхождения Excel: заголовок блока 7 повторяет блок 6, пропущена точка в №13, отличается пунктуация заголовков. Не исправляем содержание PDF и не подменяем ключ стандартной версией из интернета.

Оценки: 0 либо целые 2–10. Ровно 10 в каждом из семи блоков, 70 всего. Уточнение организатора устраняет неоднозначность фразы PDF «не превышала 10». Существующие ответы Excel используются только как контрольный пример, не как начальные ответы пользователя.

Статический HTML с встроенными CSS, данными и JavaScript. Внешних зависимостей и сетевых запросов для работы нет. Прогресс и комментарии сохраняются локально; недоступность хранилища явно показывается. Повреждённые данные не принимаются молча. Ответы не отправляются организатору автоматически.

Интерфейс: инструкция → один блок из восьми утверждений → результат. Свободный возврат к блокам. Индикатор суммы, завершённых блоков и оставшихся блоков. Результаты: восемь ролей, подробная таблица расчёта, исходные описания, личные комментарии, копирование/скачивание текста и печать. При равенстве на границе тройки показывать все связанные роли с пояснением; не вводить метод разрешения ничьей.

Размещение: файлы пригодны для GitHub Pages и российского статического хостинга. Основной российский хостинг требует аккаунта владельца. Доступность сайта из РФ подтверждается только фактическими проверками, а не выбором провайдера.
